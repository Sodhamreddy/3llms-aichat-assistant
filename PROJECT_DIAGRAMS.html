System overview

Complete project architecture

The project has a React frontend, a Node/Express Playwright backend, Supabase for users and analytics, n8n for API-mode workflow automation, and browser profiles for account-based LLM access.

Frontend: user experience Backend: orchestration Supabase: user data n8n: API workflow Playwright: browser-based LLM access

User journey

Detailed user flow

New users complete setup once. Returning users go directly to chat. In shared Browser Mode, provider accounts are already managed by the server profile.

1

Sign up or log in

User creates an account with email/password or Google login. Supabase manages account identity.

2

Choose mode

Browser Mode uses saved browser sessions. API Mode sends prompts through n8n and provider APIs.

3

Ask once

The user writes one question in the chat interface and selects ChatGPT, Claude, Gemini, or all models.

4

Review result

Individual responses appear side by side, followed by one final synthesized answer.

Prompt execution

Browser Mode vs API Mode

Excelliq supports two operating modes. Browser Mode works without official API keys by using logged-in provider accounts. API Mode uses n8n and API keys for direct automation.

B
✓

Browser Mode

The backend opens a saved browser profile, enters the prompt into ChatGPT, Claude, and Gemini, waits for responses, then returns them to the frontend. In shared mode, every user uses the same managed server-side profile.

A
n8n

API Mode

The frontend sends the prompt to the backend proxy, the backend sends it to n8n, and n8n runs the configured AI workflow. The returned response is displayed in the same comparison interface.

Browser sessions

Shared provider account flow

For demos and internal usage, Excelliq can use one shared browser profile named client_shared. This avoids asking every user to log in to each LLM provider.

Deployment

Production hosting view

The frontend can run on a static host, but Browser Mode needs a continuously running backend with Chromium installed and persistent storage mounted for browser profiles.
